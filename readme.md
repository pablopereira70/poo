# 🧩 Programação Orientada a Objetos

Repositório dedicado às soluções práticas da disciplina de Programação Orientada a Objetos, desenvolvidas em TypeScript.

## 🛠️ Tecnologias e Ferramentas

- **Linguagem:** TypeScript 📘
- **Ambiente de execução:** Node.js
- **Gerenciador de pacotes:** npm
- **Ambiente de desenvolvimento:** VS Code
- **Documentação:** Markdown `(.md)`

## 📂 Organização do Repositório

- 📁 **`src/`** : código-fonte em TypeScript
- 📁 **`build/`** : arquivos JavaScript gerados na compilação
- ⚙️ **`tsconfig.json`** : configuração do compilador

## 🎯 Competências Desenvolvidas

- **Pilares da POO:** abstração, encapsulamento, herança e polimorfismo
- **Modelagem de classes:** atributos, métodos, construtores e visibilidade
